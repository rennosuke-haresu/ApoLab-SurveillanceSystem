## このアセットでできること

VRChat ワールドに **監視カメラシステム** を追加できます。

- 管理エリアのモニターに各所のカメラ映像をリアルタイム表示
- [◀][▶][OFF] ボタンで映像を切り替え
- モニターを複数台置いて、それぞれ別の映像を表示
- モニターごとに切り替えるカメラを割り当て可能（例：受付は入口カメラだけ）
- 複数のモニターで同じカメラを表示することも可能
- 表示していないカメラは自動で OFF になるためパフォーマンスに優しい
- カメラ本体を見せたいワールド向けに、モデルつきのカメラ（壁掛け・天井付け）を別売しています（BOOTH の同じ商品ページ）

> ℹ️ **表示状態はプレイヤーごとにローカルです**  
> モニターの切り替え操作は操作した本人の画面にだけ反映され、他のプレイヤーには同期されません。各自が好きなカメラを見られる仕様です。

## セットアップ手順

全体の流れは次の通りです。

```
① RenderTexture を用意する（カメラ台数分）
② カメラを配置する
③ モニターを配置する
④ SurveillanceManager を配置して全体をつなぐ
⑤ 動作確認
```

---

### ① RenderTexture を用意する

**RenderTexture（RT）とは？**  
カメラの映像を記録するための「録画テープ」のようなものです。カメラ1台ごとに1枚ずつ必要です。

**手順**

1. `ApoLab/SurveillanceSystem/Materials/Textures/` フォルダを開く
2. `RT_Camera_Template` を右クリック → **Duplicate**（複製）
3. 名前を `RT_Camera_01` に変更
4. カメラの台数分繰り返す（例：3台なら `RT_Camera_01`〜`03`）

**RT の設定確認（Inspector）**

| 項目 | 推奨値 |
|---|---|
| Size | **640 × 360**（16:9）|
| Depth Buffer | **At least 24 bits depth (with stencil)** |
| Anti-aliasing | **None** |

> ⚠️ Depth Buffer を「No depth buffer」にすると、映像内のオブジェクトの前後関係が正しく描画されません（奥のものが手前に表示される）。必ず 24 bits を指定してください  
> ⚠️ 1280×720 以上は負荷が高くなるので避けてください  
> Quest 向け・カメラ台数が多い場合は **320 × 180** を推奨

---

### ② カメラを配置する

1. `SurveillanceCamera_Template.prefab` を Hierarchy にドラッグ
2. 名前を `SurveillanceCamera_01` に変更
3. 監視したい場所（天井・壁など）に移動・回転させる
4. **CameraController** コンポーネントを設定する（Inspector の下の方）

   | 項目 | 設定内容 |
   |---|---|
   | Camera Id | `0`（1台目）|
   | Camera Name | 場所の名前（例：`エントランス`）|
   | Target Camera | 同じ GameObject の **Camera** をドラッグ |
   | Render Texture | `RT_Camera_01` をドラッグ |

5. Ctrl+D で複製し、台数分配置する
   - Camera Id は `0, 1, 2, 3...` と**必ず連番**にすること
   - それぞれ別の RT（`RT_Camera_02` など）を設定すること

**Camera コンポーネントの既定値について**

プレハブには負荷を抑えた設定が入っています。基本的に変更不要ですが、意味は次の通りです。

| 項目 | 既定値 | 理由 |
|---|---|---|
| Target Eye | **None (Main Display)** | RenderTexture 出力では VR 用のステレオ処理が不要なため |
| Clipping Planes - Far | **100** | 監視カメラの想定距離。屋外の遠景まで映したい場合のみ広げてください |
| Culling Mask | UiMenu / MirrorReflection を**除外** | VRChat のメニューや鏡の反射を映さないため |
| Allow HDR | **オフ** | 出力先の RenderTexture が非 HDR のため、有効にしても効果がなく負荷だけ増えます |

---

### ③ モニターを配置する

1. `SurveillanceMonitor_Template.prefab` を Hierarchy にドラッグ
2. 管理エリアの壁面などに配置する

> 💡 モニターの Camera Controllers を空のままにしておくと、次の手順で SurveillanceManager が全カメラを自動で設定します

#### 立体ボタンで切り替える（任意）

画面上のボタンの代わりに、モデルの立体ボタンを押して切り替えることもできます。

1. ボタンにするオブジェクトに Collider を付ける
2. `MonitorButton` を追加し、**Target Monitor** に操作するモニター、**Action** に Previous（前へ）／Next（次へ）／Off を設定する
3. UdonBehaviour の **Interaction Text** に表示する文言（例：次のカメラ）を入れる

> 💡 押すとボタンが Press Offset だけ沈みます。向きはボタンのローカル座標です
>
> 💡 MonitorDisplay の **状態表示（任意）** に LED などの Renderer とマテリアル 2 つを入れると、映しているときと OFF で見た目が切り替わります

---

### ④ SurveillanceManager を配置して全体をつなぐ

SurveillanceManager はカメラとモニターを全部まとめて管理するオブジェクトです。シーンに **1つだけ** 置きます。

1. `SurveillanceManager.prefab` を Hierarchy にドラッグ
2. Inspector の **SurveillanceManager** コンポーネントを設定する

**All Cameras**（全カメラを登録）

- Size をカメラの台数に変更（例：3）
- Element 0 → `SurveillanceCamera_01`、Element 1 → `SurveillanceCamera_02`…
- ⚠️ **Camera Id の番号と Element の順番を一致させること**

```
正しい例：
  Element 0 → Camera Id が 0 のカメラ  ✅
  Element 1 → Camera Id が 1 のカメラ  ✅

間違いの例：
  Element 0 → Camera Id が 2 のカメラ  ❌
```

**All Monitors**（モニターを登録）

- Size を 1 に変更
- Element 0 → シーン上の `SurveillanceMonitor_01`

**All Selectors**（All Monitors と同じオブジェクトを登録）

- Size を 1 に変更
- Element 0 → 同じ `SurveillanceMonitor_01`

> 💡 All Monitors と All Selectors には**同じオブジェクト**を設定します

#### モニターごとに映すカメラを絞る（任意）

「受付のモニターでは入口カメラだけ見せたい」といった場合は、モニター側で切り替えるカメラを指定できます。

1. モニターの **MonitorDisplay** コンポーネントを選択
2. **Camera Controllers** に、そのモニターで切り替えたいカメラだけを登録

- Camera Controllers が**空**のモニター → All Cameras の全カメラを切り替えます（通常はこちら）
- Camera Controllers を**指定**したモニター → 指定したカメラだけを ◀ ▶ で切り替えます
- 指定するカメラも、All Cameras に登録しておいてください

> ⚠️ スクリプトから `_DisplayCamera(番号)` を呼ぶ場合、番号はそのモニターの Camera Controllers の中での順番になります

---

### ⑤ 動作確認

Unity の ▶ ボタンで Play Mode に入り、Console に以下が出ればOKです。

```
[SurveillanceManager] Initialization completed successfully
```

各ボタンを押して映像が切り替わることを確認してください。

確認できたら VRChat SDK → **Build & Test** で実機テストを行ってください。

## トラブルシューティング

### モニターに映像が映らない

| 確認箇所 | チェック内容 |
|---|---|
| カメラの CameraController | Target Camera と Render Texture が設定されているか |
| RenderTexture | カメラごとに**別の** RT が設定されているか（共有は不可）|
| SurveillanceManager | All Cameras にカメラが登録されているか |
| モニターの MonitorDisplay | Display Renderer に Quad の MeshRenderer がドラッグされているか |

---

### ボタンを押しても反応しない

| 確認箇所 | チェック内容 |
|---|---|
| SurveillanceManager | All Monitors / All Selectors が正しく設定されているか |
| CameraSelector | Target Monitor が設定されているか |
| ボタンの OnClick | 設定が正しいか（下記参照）|

**VRChat でのボタン OnClick 設定について**

Unity の通常のボタン設定とは違います。以下の手順で設定してください。

1. ボタンを選択 → Inspector → Button → **On Click ()** の `+` をクリック
2. Object フィールドにモニターのオブジェクトをドラッグ
3. Function のドロップダウンで `UdonBehaviour > SendCustomEvent (string)` を選択
4. 表示されたテキスト欄にメソッド名を入力する

| ボタン | 入力するメソッド名 |
|---|---|
| 前へボタン | `OnPreviousButtonClick` |
| 次へボタン | `OnNextButtonClick` |
| OFFボタン | `OnOffButtonClick` |

## パフォーマンスについて

表示中のカメラだけ有効になるため、カメラを多く置いても負荷は最小限です。

| RenderTexture の解像度 | 推奨シーン |
|---|---|
| 640 × 360 | PC 向け（標準、16:9） |
| 320 × 180 | Quest 向け・カメラ台数が多い場合 |
